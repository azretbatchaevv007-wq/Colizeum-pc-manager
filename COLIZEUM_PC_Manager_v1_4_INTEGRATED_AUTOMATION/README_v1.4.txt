COLIZEUM PC Manager v1.4

Главное изменение:
Отдельная вкладка «Автоматизация» убрана.
Автоматизация теперь находится прямо внутри «Обновление игр и приложений».

Для каждой программы:
- включить/выключить;
- изменить путь/ожидание;
- менять порядок программ кнопками ↑/↓;
- включить собственную автоматизацию;
- добавить ожидание, клик, двойной клик, клавишу, текст, логин, пароль, запуск;
- координата клика выбирается простым нажатием мыши;
- менять порядок шагов ↑/↓;
- редактировать существующий шаг;
- удалить шаг;
- отдельно проверить только автоматизацию.

Общий запуск:
1. Запускает первую программу.
2. Ждёт заданное время.
3. Выполняет её автоматизацию, если она включена.
4. Переходит к следующей программе.
5. Всё пишет в Logs.

Пароли остаются в Windows Credential Manager и в лог не записываются.
